# Dependencies

## Runtime Dependencies
- **codebase-memory-mcp** (npm, global): Code knowledge graph MCP server
- **Node.js**: Required runtime for codebase-memory-mcp

## Optional Dependencies
- **python3**: Used in the nudge hook to parse JSON input
- **jq**: Used in the reindex hook to parse tool input JSON

## No package.json / lockfile
This is a documentation project with no package manifest. Dependencies are installed globally.
