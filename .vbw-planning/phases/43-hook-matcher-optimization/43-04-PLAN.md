## Objective
Migrate 8 hook scripts from inline git traversal to sourcing the shared `hooks/lib/project-root.sh` library created by Plan 01. This eliminates ~20 lines of duplicated code per hook and enables all hooks to benefit from the `/tmp` caching. After this change, any hook invocation after the first one in a session reads PROJECT_ROOT from cache (0 git subprocesses). (REC-05 completion)

## Context
- @hooks/lib/project-root.sh -- shared library created by Plan 01; provides PROJECT_ROOT, PROJECT_HASH, CMM_SENTINEL, CTX_SENTINEL
- @hooks/project/track-cmm-calls.sh -- duplicate traversal at lines 18-42
- @hooks/project/track-ctx-calls.sh -- duplicate traversal at lines 18-42

Dev agents have codebase-memory-mcp tools (search_graph, get_code_snippet, trace_call_path) for code exploration.

## Tasks

### Task 1: Migrate counter and sentinel hooks (4 files)
**Commit:** `refactor(hooks): migrate counter and sentinel hooks to shared project-root lib`

Replace inline git traversal in these 4 hooks with sourcing:
- `hooks/project/track-cmm-calls.sh`
- `hooks/project/track-ctx-calls.sh`
- `hooks/project/cmm-sentinel-writer.sh`
- `hooks/project/context-mode-sentinel-writer.sh`

For each hook:
1. Add near the top (after shebang and comment):
   ```bash
   # --- Project root detection (shared library with /tmp cache) ---
   _LIB_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")/lib" 2>/dev/null && pwd -P)"
   if [ -f "$_LIB_DIR/project-root.sh" ]; then
     source "$_LIB_DIR/project-root.sh"
   else
     # Fallback: inline detection (pre-optimization installs)
     <keep existing traversal block as fallback>
   fi
   ```
2. Remove the inline git superproject traversal block and worktree detection block.
3. Remove inline PROJECT_HASH, CMM_SENTINEL, CTX_SENTINEL computation (now provided by lib).
4. Verify the hook still uses the same variable names (PROJECT_ROOT, PROJECT_HASH, etc.) -- they should match since the lib exports the same names.
