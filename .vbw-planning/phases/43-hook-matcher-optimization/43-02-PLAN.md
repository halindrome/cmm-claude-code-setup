## Objective
Reorder `session-gate.sh` to check the bypass allow-list BEFORE running the expensive git superproject traversal, and add a pre-traversal `git commit` check in `reindex-after-commit.sh`. These two changes eliminate ~200 git subprocess calls for session-gate and ~80 for reindex per 50-tool session. (REC-01, REC-04)

## Tasks

### Task 1: Reorder session-gate.sh bypass before git traversal
**Commit:** `perf(hooks): move session-gate bypass checks before git traversal`

Restructure `session-gate.sh` to:
1. Read stdin into INPUT variable first (`INPUT=$(cat)`).
2. Extract TOOL using lightweight approach -- use the existing python3 parse or, better, a bash-only extraction: `TOOL=$(echo "$INPUT" | grep -o '"tool_name": *"[^"]*"' | head -1 | sed 's/.*: *"//;s/"//')`. If that fails, fall back to python3 parse.
3. Move the Phase 1 universal allow-list (Agent, ToolSearch, SendMessage -> exit 0) IMMEDIATELY after TOOL extraction, before any git commands.
4. Move the Phase 2 CMM/CTX/Bash/Read/Grep/Glob bypass case AFTER Phase 1 but still BEFORE the git traversal block.
5. Only THEN run the git superproject chain walk and sentinel checks for tools that actually need gating (Write, Edit, WebFetch, etc.).

Critical: stdin can only be read once. The `INPUT=$(cat)` must happen at the top, and the git traversal + sentinel check must use `echo "$INPUT" | python3 ...` (not cat again) for any remaining JSON parsing.

Preserve all existing behavior for non-bypass tools: Write/Edit must still be blocked until CMM sentinel exists.

### Task 2: Add pre-traversal early exit in reindex-after-commit.sh
**Commit:** `perf(hooks): add pre-traversal git-commit check in reindex-after-commit`

Add an early exit at the very top of `reindex-after-commit.sh`:
1. Read stdin: `INPUT=$(cat)`
2. Quick check: `echo "$INPUT" | grep -q '"git commit\|"git  *commit' || exit 0`
3. Only proceed to git traversal and full logic if the input contains a git commit command.

This eliminates the project-root traversal + python3 JSON parse for ~95% of Bash PostToolUse calls (any non-commit Bash command).

Update the later python3 parse to use `echo "$INPUT" | python3 ...` instead of `cat` since stdin was already consumed.

### Task 4: Test reindex-after-commit early exit behavior
**Commit:** `test(hooks): verify reindex-after-commit skips non-commit Bash calls`

Create `tests/test-reindex-earlyexit.sh` that:
1. Feeds reindex-after-commit.sh a `git status` Bash JSON; verifies exit 0 (fast path).
2. Feeds an `ls -la` Bash JSON; verifies exit 0 (fast path).
3. Feeds a `git commit -m "test"` Bash JSON; verifies it proceeds to the commit-handling path (may need sentinel setup for full test).
4. Verifies the `git diff` fast-path: feeds a `git diff` Bash JSON and confirms immediate exit 0 without traversal. Also tests `git commit --amend` to confirm it proceeds to the commit-handling path. Note: the hook's grep pattern (`"git  *commit"`) already handles double-space correctly via the regex star quantifier, so a dedicated double-space test is redundant.
