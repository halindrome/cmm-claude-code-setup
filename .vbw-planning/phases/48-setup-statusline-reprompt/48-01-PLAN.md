<objective>
Fix the install_statusline bug where a second `setup.sh --project` run on an already-installed project silently skips the six component prompts. When interactive and already-installed, re-prompt each of the six booleans using the current cache value as the default: show `[Y/n]` if current=true, `[y/N]` if current=false, and map empty Enter to "keep current". Preserve the non-interactive path (`--yes`, `--force`, non-TTY) unchanged, keep `--reconfigure-statusline` functional, and leave fresh-install behavior alone.
</objective>

In `install_statusline` around the Phase 2 guard (former line 1133, the `if [ -f "$sl_config_path" ] && [ "$RECONFIGURE_STATUSLINE" = false ]; then` block):

1. Before the guard, if `sl_config_path` exists, read the six current values (`cur_cmm_total`, `cur_cmm_details`, `cur_blocks_total`, `cur_block_details`, `cur_ctx_total`, `cur_ctx_details`) from the JSON. Use python3 (matching existing setup.sh convention); fall back to `true` on parse error. Default each missing key to `true`.

2. Restructure the guard into three branches:
   - **Non-interactive / automation** (`YES_FLAG=true` OR `FORCE=true` OR `! -t 0`): keep existing silent-skip behavior — if config file exists, preserve it; otherwise write all-true defaults. No prompt output.
   - **First-time install, no config file** (`! -f "$sl_config_path"`): fall through to the existing interactive prompt block unchanged (all six default to true via `[Y/n]`).
   - **Already-installed + interactive** (`-f "$sl_config_path"` AND TTY AND not --yes/--force): call `_prompt_with_default` six times using the `cur_*` values as defaults, assign results to `sl_cmm_total`, `sl_cmm_details`, `sl_blocks_total`, `sl_block_details`, `sl_ctx_total`, `sl_ctx_details`. Fall through to the existing write-back heredoc.

3. Keep `--reconfigure-statusline` functional: if `RECONFIGURE_STATUSLINE=true`, force the interactive re-prompt branch even when other conditions would route elsewhere (e.g. settings wiped case where `has_statusline=false` but config file exists).

4. Ensure the existing `cat > "$sl_config_path" <<SLCFG` heredoc at the end of the interactive path writes the new values atomically: write to `"${sl_config_path}.tmp"` then `mv` into place.
  </action>
