## R01-AMENDMENT (DEV-05)

This section supersedes the plan's implicit zero-match expectation for residual `ctx-search-nudge` references. The YAML frontmatter above is left frozen as the historical record; this amendment is authoritative going forward.

**Residual references enumerated (3 total, all intentional):**
1. `rules/project-settings-example.json` — one `_comment` field on the replacement PostToolUse matcher naming ctx-search-nudge as the retired predecessor, for human readability of the settings example.
2. `setup.sh` — one adjacent comment documenting why the retired hook is being purged from target settings on install.
3. `setup.sh` — one entry in the `deprecated_hooks` list naming `ctx-search-nudge.sh`. This entry is *functional*: `setup.sh` purges matching hook entries from each target's `settings.json` during install. Without it, upgraders who previously installed ctx-search-nudge would retain a stale registration pointing at a deleted script.

**Why the original expectation was over-literal:**
Any naive zero-match grep for `ctx-search-nudge` across the repo would flag these three references as residual wiring and demand their removal. Removing them would (a) break the upgrade purge mechanism that removes stale ctx-search-nudge entries from existing installs, and (b) lose the human-readable provenance comments explaining the retirement. All three references are retirement infrastructure, not active wiring.

**Amended verification clause (authoritative):**
> "`rules/project-settings-example.json` `_comment` fields, `setup.sh` comments, and the `setup.sh` `deprecated_hooks` list are exempt from any zero-match `ctx-search-nudge` grep — they are retirement infrastructure, not active wiring. A valid post-retirement state is: (a) no `PostToolUse` matcher in any `settings.json` references `ctx-search-nudge`; (b) no hook script file named `ctx-search-nudge.sh` exists under `hooks/`; (c) `setup.sh`'s `deprecated_hooks` list contains `ctx-search-nudge.sh` so installers purge stale registrations."

**Resolution:** DEV-05 resolved by plan-amendment. No code change required; the 3 references are retained as intended retirement plumbing.
